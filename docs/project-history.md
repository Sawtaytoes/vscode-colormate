# Project history and attribution

ColorMate began as a fork of [Color Identifiers](https://marketplace.visualstudio.com/items?itemName=MatthewNespor.vscode-color-identifiers-mode)
by Matthew Nespor. Its identifier-to-color mapping follows the CRC8 approach
used by [Colorcoder for Sublime Text](https://packagecontrol.io/packages/Colorcoder).

The extension grew from the goal of making code easier to skim through stable
visual cues. The following earlier material explains that motivation:

- [Why I don't use VSCode](https://medium.com/@Sawtaytoes/why-i-dont-use-visual-studio-code-f5ac7274fb96)
- [Why I still don't use VSCode](https://www.youtube.com/watch?v=1OIVjK8-jA8)

Kevin Ghadyani maintains ColorMate. Noah Raskin created the project logo.

The current architecture rule for identifier colors is recorded in
[Identifier names map to stable CRC8 colors](decisions/2022-07-29-identifier-names-map-to-stable-crc8-colors.md).
